# The Monday Morning Drip

Pediatric med ed for the busy educator. A new issue every Monday.

Read it at https://bethlinkstorwekar.github.io/Monday_Morning_Drip/

- `content/issues/` - one JSON file per issue
- `scripts/build_site.py` - builds the site into `docs/` (served by GitHub Pages)
- `PUBLISHING.md` - how a new issue gets added each week
